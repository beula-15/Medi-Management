# Medi-Management
The Online Doctor Appointment Booking System is a web-based application developed using Python (Flask) and SQLite. It is designed to automate and streamline the complete appointment process — from doctor browsing and schedule selection to appointment booking, status tracking, and medical record management. The system provides real-time updates, efficient doctor scheduling, and secure handling of patient data, reducing manual effort and improving overall operational efficiency. 
The platform enables patients to easily search for doctors based on specialty, view available time slots, and book appointments with minimal effort. Doctors can manage their schedules, view upcoming appointments, and provide digital prescriptions. Patients are also given the ability to upload their medical records such as scans and reports, which can be accessed by doctors during consultation for better diagnosis and treatment. 
With the integration of real-time communication using Socket.IO and SMS notifications via Twilio, the system ensures that users receive timely updates regarding appointment confirmations, cancellations, and status changes. Additionally, the admin module provides centralized control over doctors, patients, and appointments, helping in efficient system monitoring and management. Overall, the system aims to enhance healthcare accessibility, improve patient experience, and provide a reliable digital solution for modern appointment management.
